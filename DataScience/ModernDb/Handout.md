**Course Description:** Foundations of Structured Data Management – SQL; Distributed Database Architecture; CAP theorem trade-offs; ACID vs BASE; NoSQL Data Stores: Key-Value Stores, Document Stores, Column Family and Graph Databases; Cloud Databases and NewSQL Systems; Overview of Data Warehouses, Data Lakes, and Lakehouse Architecture; Specialized Databases: Vector, Streaming, Temporal and Spatial Databases; Emerging Trends in Data Systems.

**Course Objectives**

|   |   |
|---|---|
|**No**|**Course Objective**|
|**CO1**|Introduce learners to the evolution of modern data management systems and emerging database paradigms beyond traditional relational databases.|
|**CO2**|Develop an understanding of distributed database architectures, scalability, consistency models, and modern transaction processing approaches.|
|**CO3**|Familiarize learners with NoSQL, cloud-native, and NewSQL database systems for handling diverse and large-scale enterprise data requirements.|
|**CO4**|Provide knowledge of modern enterprise data platforms, including data warehouses, data lakes, and Lakehouse architectures.|
|**CO5**|Expose learners to specialized databases such as vector, streaming, temporal, and spatial databases for intelligent and domain-specific application|

**Learning Outcomes: Students will be able to**

|   |   |
|---|---|

**Modular Content Structure****:**

**Module 1: Foundations of Structured Data Management**

● Foundations of structured data systems

● Relational data management principles

● Data modelling and query foundations

● Transaction processing concepts

**Module 2: Distributed Database Architecture and Consistency Models**

● Distributed database principles and architectures

● Scalability, replication, and distributed processing

● Consistency and availability in distributed environments

● Distributed transactions and consistency paradigms

**Module 3: NoSQL Data Stores**

● Motivation and characteristics of NoSQL systems

● Key-value, document, column-family, and graph databases

● Flexible and scalable data models

● Querying and applications of NoSQL systems

● Querying techniques for NoSQL and search databases

● Full-text search, indexing, and relevance-based retrieval

**Module 4: Cloud Databases and NewSQL Systems**

● Cloud-native database systems and DBaaS

● Scalability and multi-region database architectures

● NewSQL systems and distributed transaction support

● Comparative perspectives on modern database systems

**Module 5: Data Warehouses, Data Lakes and Data Lakehouse**

● Data warehouse architectures and analytical systems

● Data lakes for structured, semi-structured, and unstructured data

● Evolution toward Lakehouse architectures

● Unified analytics platforms and enterprise data systems

**Module 6: Specialized Databases for Modern Applications**

● Vector databases and semantic retrieval systems

● Streaming and real-time data systems

● Temporal databases

● Spatial databases

**Module 7: Emerging Trends in Data Systems**

● Evolution of modern enterprise data systems

● Intelligent and autonomous database technologies

● Distributed and multimodal and secure data systems

● Future directions in AI-enabled data management

**Objective of Experiential Learning Component:**

Hands-on sessions on the implementation, querying, and management of modern database systems, enabling learners to gain practical experience with relational, NoSQL, graph, cloud, NewSQL, vector, and streaming databases using contemporary database platforms and tools.

**Scope of Experiential Learning Component:**

**Lab Infrastructure:** Osha Lab Platform(3 node cluster)

**Tools:** MySQL, PostgreSQL, Redis, MongoDB, Apache Cassandra, Neo4j, AWS RDS, CockroachDB, ChromaDB, ksqlDB, MongoDB Atlas, Docker, Jupyter Notebook

# 08. Linked List

Pointer surgery. Master the dummy-head and prev/curr/next dance.

## Ladder

1. [Basics & reversal](01-basics-reversal.md) — reverse, merge, middle

## Core idea

Use a **dummy head** to avoid special-casing the first node. Use **fast/slow** for middle and cycle. Reverse is prev/curr/next.

# Bit — XOR Basics

XOR cancels equal pairs → find the odd one out with O(1) space.

| LC# | Diff | Question | Pattern | Companies |
|---|---|---|---|---|
| 136 | Easy | Single Number | XOR all → the unpaired | Amazon, Google |
| 268 | Easy | Missing Number | XOR indices vs values | Amazon, Microsoft |
| 389 | Easy | Find the Difference | XOR both strings | Google, Amazon |
| 461 | Easy | Hamming Distance | popcount(a ^ b) | Amazon, Google |

**Key skill**: XOR of a value with itself is 0 — pair up known elements and the leftover is the answer (LC 136, 268).

flex: 1 1 0 Explained + Flex vs Grid

1. What is flex: 1 1 0?

flex: <flex-grow> <flex-shrink> <flex-basis>
PropertyValueMeaning
flex-grow1Item CAN grow to fill available space (proportional share)
flex-shrink1Item CAN shrink if container is too small
flex-basis0Start from 0 width, then distribute ALL space equally
Key insight: flex-basis: 0 means "ignore my content width, divide space purely by grow ratio."
flex-basis: auto means "start from my content width, then distribute REMAINING space."

3.5 — WHAT DOES 1D vs 2D ACTUALLY MEAN?

1D (Flexbox) = You control items in ONE direction at a time. Either a row OR a column. Never both.
2D (Grid) = You control items in BOTH directions at the same time. Rows AND columns together.

🔴 FLEXBOX is 1D — Items only flow in ONE line

4. Flex vs Grid — Key Differences

AspectFlexboxGrid
Direction1D — row OR column2D — rows AND columns simultaneously
ControlChildren decide their own size (flex-grow)Parent defines the layout structure
Content vs LayoutContent-first (sizes flow from items)Layout-first (sizes defined on container)
AlignmentAlong one axis at a timeBoth axes at once
OverlapNot possibleItems can overlap (grid-area)
Best forNavbars, card rows, centering, dynamic itemsPage layouts, dashboards, complex 2D arrangements
Equal sizingflex: 1 1 0 (hack-ish)1fr 1fr 1fr (natural)
Gap supportYes (gap)Yes (gap, row-gap, column-gap)

6. Quick Cheat Sheet

ShorthandExpands toUse case
flex: 1flex: 1 1 0Equal share, ignore content
flex: autoflex: 1 1 autoGrow from content width
flex: noneflex: 0 0 autoRigid, no flex at all
flex: 0 autoflex: 0 1 autoDefault browser behavior
flex: 2flex: 2 1 0Double share vs flex:1 siblings
Rule of thumb:
• Use Flexbox when items flow in ONE direction (navbar items, card row, centering).
• Use Grid when you need to control BOTH rows and columns (page layout, dashboard, gallery).
• They work great TOGETHER — Grid for page structure, Flex for component internals.
